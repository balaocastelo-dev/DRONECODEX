# AeroVision Premium V4 — Cinematic Parallax

Site estático HTML/CSS/JS com cena aérea, camadas atmosféricas animadas pelo scroll e drone WebGL 3D procedural inspirado no Mini 3.

## Testar

Execute `python -m http.server 8000` nesta pasta e acesse `http://localhost:8000`. O módulo WebGL importa Three.js de CDN e exige conexão à internet; existe fallback SVG local.

## Publicar

Hospede todos os arquivos preservando a estrutura. Configure domínio, URL canônica, sitemap, Search Console, Analytics e substitua imagens demonstrativas por portfólio autorizado. Os movimentos de 500 m são apenas cinematográficos, não altitude de operação. Verifique licenças e condições de voo antes de anunciar.

## Observação

O drone é uma interpretação geométrica 3D, não um modelo CAD/fotogramétrico oficial DJI Mini 3. A paisagem é ilustrativa e não representa uma fotografia georreferenciada de Campinas.
